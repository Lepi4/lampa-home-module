# Shield: качество в описании и поиск, APK 1137

03.11.2026. Приёмка выполнена на NVIDIA Shield `192.168.1.112:5555`, модель
SHIELD Android TV, основной профиль `u_default`, домашний сервер `192.168.1.80`.
Изменён только APK. Серверный модуль, ядро и службы не менялись.

## Что исправлено

Правая панель описания читала только `release_quality` / `cp_quality` карточки,
тогда как постер также использовал клиентский кэш качества. Теперь оба места
используют один источник; ответ фонового запроса обновляет описание, если та же
карточка ещё выбрана. Результат после смены профиля не переносится в другой
профиль, при смене фокуса старая карточка не возвращается в описание. Ключ
кэша одинаково различает фильмы и сериалы, включая записи с first_air_date.

Поиск воспроизведён по экрану владельца: `гангстерлэнд`, категория «Сериалы»,
ответ пустой. TMDB находит `Гангстерленд` / `MobLand` (TV ID 247718), но не
варианты с «э» или дефисом `гангстер-ленд`. Другие запросы (Матрица, Офис,
Keanu) уже работали; общего отказа сервера поиска не было.

При пустом исходном ответе без продолжения каталог теперь делает ровно одну
дополнительную попытку: «э/ё» заменяются на «е», дефис между кириллическими
буквами убирается. Успешный исходный запрос не меняется. Ошибка HTTP, пустая
отфильтрованная страница с next_page и поиск YouTube не запускают такой повтор.
Введённый текст, категория, период, страна и рейтинг сохраняются. Кнопка
«Показать ещё» продолжает выбранный нормализованный запрос.
