# Приложение Android

Пакет `app.lampac.home.mc` (flavor `mc`, «Lampa Media Center»), Android 5.0+ (minSdk 21), рассчитано на Android TV / приставки.
Готовая сборка: `release/LampaMediaCenter-release-<дата>.apk`. Исходники выпуска: `release/src-<дата>`.

## Установка готовой сборки

По ADB (Wi-Fi или сеть):

```bash
adb connect <IP-приставки>:5555
adb install -r release/LampaMediaCenter-release-20261028.apk
```

Или скопируйте APK на флешку и откройте файловым менеджером приставки (разрешите установку из неизвестных источников).
Обновление поверх уже установленной версии работает, если подпись та же (тот же ключ, см. ниже); версию с чужой подписью нужно сначала удалить.

## Подключение к серверу

При первом запуске приложение само ищет сервер в локальной сети: проверяет адреса вашей подсети `/24` на порту 9118.
Если не нашло (другая подсеть, VPN), введите адрес вручную: `http://<HOST_IP>:9118`. Адрес запоминается.

## Что приложение делает само

- Встроенные плееры: ExoPlayer (кино, сериалы, YouTube, эфир) и mpv (эфир).
- **AFR**: подбирает частоту экрана под частоту кадров видео (24 / 23,976 / 25 / 30 / 50 / 60 Гц); переключатель — в настройках плеера и ТВ.
- **DRC**: «Настройки Lampa → Звук — все источники → Динамика звука»: выключена / мягкая / ночная; применяется со следующего запуска плеера.
- **Проброс звука**: в тех же общих настройках лаунчера, рядом с АФР. Только «Вкл» / «Выкл», по умолчанию выключен. Общий для всех профилей одной приставки и всех источников встроенного плеера. При включении DRC временно не применяется, её выбранный режим сохраняется и возвращается после выключения проброса. Изменения действуют со следующего запуска плеера. Подробности и ограничения — [AUDIO.md](AUDIO.md).
- **Настройки в плеере**: кнопка ⚙ в ExoPlayer и MENU в mpv открывают общие АФР, проброс, DRC и туннелирование A/V. Значения совпадают с лаунчером; применяются при следующем открытии плеера.
- Отправка прогресса просмотра на сервер с очередью на диске (не теряется при обрыве сети).
- Диагностический журнал (если включён на сервере), см. [OPERATIONS.md](OPERATIONS.md).

## Сборка из исходников

Требования: JDK 17, Android SDK (compileSdk 34), доступ к интернету для Gradle.

```bash
cd LAMPA
# Windows: путь с кириллицей ломает Gradle — подмонтируйте диск:  subst L: "<путь к проекту>"  и работайте из L:\LAMPA
./gradlew assembleMcRelease          # Windows: gradlew.bat assembleMcRelease
# результат: app/build/outputs/apk/mc/release/app-mc-release.apk
```

В `local.properties` должен быть путь к SDK (`sdk.dir=...`). Файл создаёт Android Studio.

### Подпись

Релизную сборку подписывает **ваш** ключ. Репозиторий ключей не содержит. Укажите его одним из способов:

1. файл `LAMPA/app/keystore/keystore_config` (не публикуется) со строками `storeFile=…`, `storePassword=…`, `keyAlias=…`, `keyPassword=…`;
2. переменные окружения `KEYSTORE_FILE`, `KEYSTORE_PASSWORD`, `RELEASE_SIGN_KEY_ALIAS`, `RELEASE_SIGN_KEY_PASSWORD`.

Создать ключ: `keytool -genkeypair -v -keystore lampa-home.jks -alias lampa -keyalg RSA -keysize 2048 -validity 10000`.
**Храните ключ и пароль в безопасном месте**: без того же ключа новую версию нельзя будет установить поверх старой.
Сборка с другим ключом, чем у выпущенного APK, потребует удалить приложение на устройствах и поставить заново.

### Адрес сервера по умолчанию

В `app/build.gradle` (`defaultAppUrl`) и в экране подключения `app/src/mc/assets/shell/shell.js` есть адрес-подсказка `http://192.168.1.80:9118`
для ручного ввода. Для своей установки можно заменить на ваш адрес и пересобрать, но это не обязательно: сервер находится автопоиском или вводится вручную.
