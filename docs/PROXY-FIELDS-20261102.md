# HomeMedia 2026.11.02.5 — редактируемые поля прокси

Отдельная категория «Прокси» и список именованных подключений убраны.
В секциях YouTube и Кинопаба находятся обычные редактируемые поля с текущими
адресами. Поля TMDB (API и изображения отдельно) и JacRed — в состоянии сервера.
Рядом с каждым полем: «Без прокси», «Проверить», «Сохранить».

Подставляются действующие значения: SOCKS5 `192.168.1.61:7893` для TMDB и
Кинопаба, HTTP `192.168.1.61:7890` для YouTube, «Без прокси» для JacRed.
Наши адреса также доступны в подсказках поля. Авторизация сохранена на сервере;
раскрывающийся блок позволяет её заменить или удалить.

Сохранение одного поля не меняет остальные сервисы и не сохраняет их черновики.
При отделении от общего подключения пароль копируется только на сервере,
в браузер не выдаётся. Выбор известного SOCKS5-адреса для JacRed сохраняет
возможность использовать уже настроенную авторизацию. Откат остаётся доступен
в состоянии сервера.

Проверено: 9 регрессий формы, синтаксис полного скрипта панели и повторные
56 HTTP-контрактов в изолированном Lampac, включая сохранение авторизации
при создании независимого подключения. Текущие маршруты при установке
не переключались. APK остаётся 1132, относительные ссылки служб сохранены.

`/opt/lampac-backups/inline-proxy-20261102`.
