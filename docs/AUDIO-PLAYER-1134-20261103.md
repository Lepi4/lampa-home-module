# APK 1134 — общие настройки звука и меню плеера

Версия `1.16.16-mc`, пакет `app.lampac.home.mc`, versionCode `1134`.
Проверки и установка выполнены только на TOX3 Plus в спальне
`192.168.1.56:5555`, основной профиль. Shield в этой проверке не использовался.

## Изменения

- В лаунчере: «Проброс звука» с двумя значениями «Вкл» / «Выкл»; по умолчанию
  выключен. При включении DRC обходится, её выбранный режим сохраняется.
- Кнопка ⚙ в ExoPlayer открывает общие АФР, проброс, DRC и туннелирование A/V.
  В mpv тот же диалог открывается кнопкой MENU; INFO показывает статистику.
- Настройки одинаковы для ТВ, потоков и торрентов, общие для профилей приставки.
  Применяются при следующем открытии плеера; это подписано в диалоге.
- Изменение АФР из нативного диалога синхронизируется с записью приставки на
  сервере. Старые ответы не отменяют ожидающий синхронизации выбор; быстрые
  повторные переключения отправляют последнее значение.
- После изменения режима экрана восстановившиеся возможности HDMI передаются
  в DefaultAudioSink на потоке воспроизведения. Это сбрасывает ограничение PCM,
  которое Media3 сохраняет после временной recoverable-ошибки AudioTrack.
- Для mpv добавлена однократная попытка PCM при распознанной дорожке и
  неоткрывшемся IEC61937-выходе, чтобы не повторять зависший старт.

Подробности: [AUDIO.md](../docs/AUDIO.md).

## Проверки и границы результата

- Release APK и lintVital: успешно; подпись совпадает с предыдущими выпусками.
- 5 JUnit-проверок политики DRC/проброса и 20 Node-регрессий пройдены.
- На установленном окончательном APK выполнены 14 сценариев: HEVC 1080p с
  AC3/E-AC3/DTS/AAC в ExoPlayer, AC3 в mpv, настоящий Sintel из TorrServer и
  эфир BOX Anime. Каждый источник проверен с выключенным и включённым пробросом.
  Воспроизведение и ход времени подтверждены логами; при корректном закрытии
  между сценариями процесс приложения не перезапускался.
- Диалог настроек проверен через реальные элементы Android: четыре пункта,
  переключение проброса, сохранение DRC, АФР и его серверная синхронизация,
  туннелирование, возврат из диалога к текущему воспроизведению. Подтверждено
  сохранение последнего значения при быстрых изменениях АФР.
- Отдельная воспроизводимая регрессия использует классы установленного APK:
  потерянные возможности sink заменяются объявлением поддержки AC3; при
  выключенном пробросе PCM остаётся. Сценарий и Java-фикстура находятся в
  `server-mod/tests/audio-recovery.regression.py` и `fixtures/android/`.

**Ограничение:** Android на текущем HDMI-подключении спальни объявляет PCM,
но не AC3/E-AC3/DTS/DTS-HD/TrueHD. Поэтому проверены декодирование/возврат в PCM
и восстановление состояния sink с имитацией HDMI, а **реальная передача
bitstream на внешний ресивер, в том числе после АФР, не подтверждена**.
Наличие IEC61937-профиля само по себе не означает объявленную поддержку Dolby.

Ранний автоматический сценарий ошибочно использовал BACK для закрытия mpv,
открывая список каналов вместо выхода. Окончательная матрица использует явную
остановку и проверяет сохранение PID. Ошибки вспомогательных диагностических
процессов не учитывались как ошибки приложения.
