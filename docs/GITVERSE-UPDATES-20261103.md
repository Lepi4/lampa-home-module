## Реализация

`release_sources.py` поддерживает прежний GitHub API и публичный GitVerse-манифест.
API релизов GitVerse без авторизации возвращал 401, публичные raw-файлы — 200,
поэтому серверу не требуются API-токены или приватные SSH-ключи.

`module-release.json` содержит полный коммит `artifact_ref`, версии, пути,
размеры и SHA-256. Файлы скачиваются из этого коммита. Изменяемая ветка служит
только указателем на последний манифест; публикационный скрипт сохраняет файлы
версии неизменяемыми и проверяет подпись APK до отправки.

Сервер проверяет формат метаданных, размер, SHA-256 и монотонность versionCode.
При ошибке текущее APK и `latest.json` сохраняются. Смена источника при той же
версии не уничтожает `previous-latest.json` предыдущей версии.

На домашнем Proxmox `192.168.1.30` и в CT116 `lampac / 192.168.1.80` установлены
новые скрипты и конфиг. HomeMedia и Channel Manager переключены на GitVerse;
официальные источники сторонних компонентов сохранены. В данных веб-панели
отображается «Источник: GitVerse», ошибок проверки источника нет.

Для APK включён `lmpc-apk-sync.timer` — каждые 30 минут. Прежний GitHub-таймер
отключён. Настройка: `/opt/lmpc-control/apk-source.json`; `enabled=false`
отключает даже ручное скачивание. Команда отключения расписания:
`systemctl disable --now lmpc-apk-sync.timer` внутри CT116.

Режимы автоматизации медиакомпонентов сохранены: HomeMedia — off, Channel
Manager — check. Автоматическое применение обновлений не включалось.
