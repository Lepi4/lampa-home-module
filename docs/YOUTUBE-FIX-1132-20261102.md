# YouTube: HomeMedia 2026.11.02.3 / APK 1132

Исправления установлены на CT116 `192.168.1.80:9118` и TOX спальни
`192.168.1.56:5555`. APK `1.16.14-mc`, versionCode `1132`.
Shield и детская приставка в этой проверке не использовались; новая APK доступна
им через обычное предложение обновления с сервера.

## Что изменилось

- Получение ссылок: основной клиент yt-dlp, затем ограниченные по времени
  `web_embedded` и `android_vr` при подходящих отказах. Удалённое/закрытое видео,
  ограничение частоты запросов и занятый сервер не запускают перебор заново.
  Прокси, cookies и учётные записи Google не менялись.
- Ссылки проверяются по сроку действия с запасом 120 секунд и маршруту прокси.
  После 403/404/410 медиапрокси один раз получает новую ссылку того же формата.
- Каждый блок потока проверяет HTTP-статус, Content-Range и общий размер файла.
  Сетевой обрыв продолжается с подтверждённого смещения, временные ошибки
  повторяются ограниченно. Тело ошибки не подмешивается в видео.
- Исправлены суффиксные, перевёрнутые и переполненные Range. Неверный диапазон
  возвращает 416 вместо целого файла, пустого успешного ответа или 500.
- Одинаковые запросы ролика объединяются. Отмена одного зрителя не мешает
  другому; последний ушедший зритель отменяет ненужное извлечение.
  Ожидание свободного процесса ограничено 10 секундами, процессов максимум три.
- Постоянное окно подготовки закрывается кнопкой «Назад». Уход со страницы
  отменяет запрос и запрещает поздний запуск плеера. Ошибки сети, проверки
  подключения, недоступного ролика и перегрузки получают разные сообщения.
- Exo восстанавливает YouTube после сетевой ошибки через новые метаданные,
  сохраняя текущую позицию, метаданные и предел качества. Максимум два
  восстановления за 120 секунд; завершение плеера отменяет запрос.
  Ответ в фоне не включает воспроизведение. Сервер передаётся и для трейлеров
  без записи истории; единственное прогрессивное качество сохраняет свой предел.

## Проверено

Изолированная копия действующего Lampac с отдельной БД и сетевым пространством
успешно скомпилировала модуль и загрузила обязательные модули аниме.
20 серверных контрактов прошли: передача нескольких блоков, 403 на втором
блоке, 503 без повреждения тела, усечённое чтение, ограничение повторов,
Range, отмена, объединение запросов, срок ссылок и классификация ошибок.
Тестовый контроллер отсутствует в рабочем manifest.

```powershell
python server-mod/tests/youtube-reliability.regression.py
node --test server-mod/tests/youtube-playback.regression.cjs server-mod/tests/youtube-pagination.regression.cjs server-mod/tests/trailer-focus.regression.cjs
```

Дополнительная выборка регрессий клиента, профилей, метаданных, AFR, оболочки,
трейлеров и YouTube прошла: 49/49 пунктов Node runner, включая отдельный
набор из 22 профильных проверок. Release APK собрана JDK 17, прошла
`lintVitalMcRelease`, проверку пакета и подписи прежним ключом.

На действующем сервере все пять ID `yg3lhpstv3E`, `Oj1DRANJXhI`, `jNQXAC9IVRw`,
`cUI_5wE3KfM`, `5sZf0atxRSQ` получили свежие ссылки, видео и звук читаются с HTTP 206.
В предыдущем аудите первые три возвращали `no_stream` из-за проверки YouTube.
Холодное получение занимало около 10 секунд, повторное — менее 0,01 секунды.
Для коротких роликов запрос за концом файла корректно возвращает 416.

Суффиксный запрос вернул ровно 32768 последних байтов; чтение через границу
8 МиБ вернуло 8421376 байтов. Искусственно испорченная подпись была обновлена
сервером: HTTP 206, 32768 байтов совпали с исходным потоком, около 11 секунд.

На TOX подтверждены вывод кадров и звук ранее отказавшего ролика
480×854 H.264/AAC, 25 кадров/с без потерь на проверенном участке.
После искусственной HTTP-ошибки Exo получил новые ссылки и воспроизводил
1920×1080 H.264/Opus, после старта/AFR — около 30 кадров/с.
Проверены видимое окно подготовки, физическая кнопка «Назад», отсутствие
позднего открытия плеера и возврат фокуса. Точные тайминги позиции после
восстановления отдельно не сверялись: скриншоты нативного режима чёрные,
UIAutomator не получил idle; сохранение позиции проверено по коду.

Сеанс остался в Основном профиле, тестовые профили не создавались;
ролики запускались с `remember=false`. Временные файлы и ADB forwarding
после проверки удалены. Настройки AFR и профилей не менялись.

  Полученный с сервера файл проверен по SHA-256.
- Серверная копия до изменения: `/opt/lampac-backups/youtube-fix-20261102`.
  Сохранены прежние `Youtube.cs`, `youtube.js`, `manifest.json`, снимок `home.db`

  исходных файла и перезапустить Lampac. Снимок БД без необходимости не
  восстанавливать, чтобы не потерять новый прогресс просмотра.
- APK 1131 остаётся на сервере и в прежнем GitHub-релизе; на TOX возможна
  установка прежней подписанной версии через `adb install -r -d`.

Ограничения: выборка мала; многочасовое воспроизведение, трансляции,
закрытые и возрастные ролики не проверены. YouTube может менять требования
к клиентам и ограничивать выходной IP. Запасной клиент повышает доступность,
но не гарантирует запуск каждого видео. Публичный доступ GitHub проверяется
отдельно: восстановленный CLI-вход не доказывает доступность релиза серверу
без авторизации.

Релиз опубликован: https://github.com/Lepi4/lampa-home-module/releases/tag/2026.11.02.3
Исходники: commit `cc4516d`. GitHub подтвердил размеры и SHA-256 обоих вложений.
Повторная проверка из CT116: анонимный GitHub API отвечает HTTP 404.
Это остаётся внешним ограничением публикации/учётной записи; обновление через
GitHub пока не считается рабочим. Локальный APK-манифест и скачивание — HTTP 200.
