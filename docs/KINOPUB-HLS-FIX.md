# KinoPub: HTTP 403 при открытии HLS

Исправление HomeMedia 2026.11.13.4, 13 ноября 2026 года. APK 1160 совместим, пересборка приложения не требуется.

## Причина

API KinoPub возвращает адреса HLS4/HLS2 с хостом `api.service-kp.com`. Этот адрес уже присутствовал среди API-зеркал в `KpStore.ApiHosts`, однако `KinoPubController.HostAllowed` разрешал только прежние домены. В результате `/kp/stream/...m3u8` возвращал локальный HTTP 403 с `error=host_not_allowed`, а ExoPlayer показывал `ERROR_CODE_IO_BAD_HTTP_STATUS`.

Дефект зависит от хоста в выданном API адресе: ссылка через `api.srvkp.com` проходила прежнюю проверку. После перезапуска выбор API-зеркала может измениться; поэтому один успешный просмотр сам по себе не проверяет исправление для другого зеркала. Ограничение Lift на 1080p в этом отказе не участвует.

## Код

В существующую проверку добавлен ровно один хост:

```csharp
static bool HostAllowed(string host)
    => host == "api.service-kp.com"
       || host == "kino.watch" || host.EndsWith(".kino.watch")
       || host == "srvkp.com" || host.EndsWith(".srvkp.com")
       || host.EndsWith(".cdntogo.net") || allowedHosts.ContainsKey(host);
```

Не нужно разрешать весь Интернет, снимать проверку доменов или добавлять подстановку для любых поддоменов `service-kp.com`. Профильная авторизация, ограничения качества других источников и обработка таймингов не менялись.

## Проверка

Полная сборка исходников HomeMedia: 0 ошибок. `server-mod/tests/KpStreamHostFixture.cs`: 9 успешных сценариев, включая отклонение похожих доменов, посторонних хостов и loopback.

На рабочем сервере до изменения воспроизведён `403 host_not_allowed` для реального HLS4 URL, выданного API. После изменения проверен HTTP 200 с `#EXTM3U` именно через `api.service-kp.com`, в дополнение к прежнему `api.srvkp.com`.

Для трёх позиций проверена цепочка: карточка → мастер-плейлист → видео- и аудиоплейлисты → первые сегменты. Плейлисты возвращают HTTP 200, Range-запросы к сегментам — HTTP 206. Владелец Shield подтвердил, что воспроизведение снова запустилось. Проверка первых сегментов не является проверкой непрерывного просмотра до конца фильма.
