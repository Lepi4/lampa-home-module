# HomeMedia 2026.11.02.4 — прокси и относительные ссылки служб

В `/home` добавлен общий раздел «Прокси». Действующие настройки импортированы
и сохранены без смены маршрута:

| Сервис | Подключение |
|---|---|
| TMDB — описания | Mihomo SOCKS5 `192.168.1.61:7893` |
| TMDB — постеры | то же |
| Кинопаб — API и серверное видео | то же |
| YouTube — поиск, подписки и серверное видео | Mihomo HTTP `192.168.1.61:7890` |
| JacRed — запросы агрегатора `/jr` | Без прокси |

Для каждого пункта доступен независимый выбор «Без прокси», SOCKS5 или HTTP.
Администратор может добавлять подключения, менять адрес и авторизацию,
проверять значения до сохранения и возвращать предыдущий вариант. Кнопка
проверки JacRed опрашивает включённые источники агрегатора, а не один сайт.
Изменения в другом окне защищены проверкой ревизии.

Реальные сохранённые учётные данные импортируются на сервере; в исходниках,
пакете и ответах браузеру их нет. Новые значения передаются JSON-телом POST,
не строкой запроса. Детский и обычный взрослый профили не могут читать,
сохранять, проверять или откатывать общие настройки прокси.

TMDB: точечно обновляются два блока `init.conf`; штатное перечитывание
конфигурации проверено на реально загруженном модуле TmdbProxy в изоляции.
Кинопаб, YouTube и JacRed применяют выбор к новым HTTP-запросам. `Без прокси`
явно выключает использование прокси, включая переменные окружения клиента.
Прокси YouTube участвует в проверке актуальности закэшированных ссылок.

## Ссылки служб

Ссылки в панели относительные, без фиксированного IP и внешних портов:

- `/home/services/channel-manager/`
- `/home/services/torrserver/`
- `/home/services/tvheadend/gui/`

Lampac передаёт их строго на фиксированные `127.0.0.1:3002`, `:8090`, `:9981`
внутри CT116. Произвольный внешний адрес передать нельзя. Передача адаптирует
пути HTML/CSS и браузерных fetch/XHR/EventSource/WebSocket-запросов; данные API
и файловые пути в настройках не переписываются. POST сохраняет тело и длину.
Cookies служб ограничены своим относительным путём; сеанс HomeMedia в службу
не передаётся. Tvheadend сохраняет собственную проверку логина и пароля.
Интерфейсы служб доступны через эти пути только администратору HomeMedia.

## Проверки и ограничения

Изолированный запуск копии рабочего Lampac: 53 HTTP-контракта, включая
авторизацию, сохранение секретов, отдельный direct для каждого сервиса,
откат (в том числе после повторного сохранения без изменений), перечитывание TMDB, исправление отдельно изменённого init.conf,
HTTP-интерфейсы служб и POST. Тестовые профили и контроллер существуют
только во временной копии, в рабочую установку не попадают.
Дополнительно проверены реальные HTTP-обработчики клиентов и явный пустой
аргумент `--proxy` для yt-dlp при выборе прямого подключения.

Node: 7 проверок формы и относительных ссылок, 4 проверки преобразования
браузерных запросов. Связанные регрессии профилей, метаданных, оболочки и
YouTube прошли. Дополнительно прошли 20 серверных контрактов YouTube.

На действующем CT116 проверены импорт и сохранение без смены маршрутов,
сохранение прежней авторизации Кинопаба и точное совпадение init.conf
с резервной копией. Проверки соединения дали:

- TMDB API — 401 без ключа API: сервис доступен; это не ошибка прокси.
- TMDB-постер — 200.
- Кинопаб API — 401 без токена: сервис доступен.
- YouTube — 204; дополнительно метаданные ролика 200 и 32768 байтов видео 206.
- JacRed — два источника 200, jacred.su 429. Это проверка соединения,
  наличие нужной раздачи и качество выдачи ею не подтверждаются.
- Относительный интерфейс Channel Manager и его API — 200.
- Относительный интерфейс TorrServer и `/echo` — 200.
- Относительный интерфейс Tvheadend без его логина — ожидаемые 401 и
  WWW-Authenticate.

Браузерный инструмент в этой сессии недоступен: не подключены ни браузеры,
ни Windows UI. Полный визуальный прогон реальных интерфейсов и длительные
WebSocket/SSE-сеансы не подтверждены. HTTP-передача и преобразование запросов
проверены отдельно; эти ограничения не заменены утверждением о полном UI-тесте.

Резервная копия: `/opt/lampac-backups/proxy-panel-20261102` — прежние файлы
модуля, init.conf, kinopub.json и SQLite-снимок home.db. Для отката кода вернуть
сохранённые файлы модуля и перезапустить Lampac; снимок БД без необходимости
не восстанавливать, чтобы сохранить новый прогресс. Возврат настроек прокси
в текущем модуле выполняется отдельной кнопкой панели.

Новая APK не требуется: текущая 1132 остаётся прежней. Mihomo, его правила,
Homepage CT120 и конфигурации самих трёх служб не изменялись.
