# APK 1131 / 1.16.13 — 02.11.2026

Пять исправлений: глобальная настройка AFR для всех источников и профилей одного
устройства; компактные два ряда управления, SUB с выключенными по умолчанию
субтитрами; стрелки ±15 с и кнопки ±30 с; устойчивое ожидание метаданных
автоторрента; границы списков серий и возврат из карточки в оболочку.

AFR хранится в общей настройке устройства, синхронизируется из оболочки и ТВ.
Exo и mpv используют её даже при противоречащем extra `tv_afr=1`.
Встроенное голосование Media3 за частоту остаётся выключенным.

Автоподбор использует самостоятельные запросы метаданных: штатный метод ядра
не вызывает callback при отсутствии file_stats. Зависший кандидат ограничен
10 секундами, поиск и проверка в целом — 90 секундами; если уже есть проверенный
кандидат, он запускается по общему таймауту. Отложенный запуск отменяется по Назад.
Индикатор показывает поиск, проверку файлов и запуск; затем используется штатное
окно буферизации TorrServer. Ошибка без подходящих файлов открывает ручной выбор.

Возврат: прежний код мог принять недавнее событие главной TMDB за границу новой
карточки. Теперь начало команды из оболочки запоминает исходный экран; граница
фиксируется по следующему отличающемуся экрану, исключая main.

Проверено на **TOX спальни 192.168.1.56:5555**, установка с сохранением данных.
Детская приставка и Shield для этого набора изменений не использовались.

  утверждает доступность всех внешних индексаторов и раздач.
