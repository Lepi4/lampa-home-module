# Прокси

В установленном HomeMedia откройте `/home`. В разделах **YouTube** и **Кинопаб**
есть редактируемое поле прокси, а настройки TMDB (API и постеры отдельно) и
JacRed находятся в блоке **«Состояние сервера»**. В поле можно вписать адрес
или выбрать **«Без прокси»**; рядом находятся кнопки **«Проверить»** и **«Сохранить»**.
Каждая кнопка сохраняет только свой сервис: изменение Кинопаба не меняет TMDB.
Отдельной категории и обязательного выбора именованного подключения нет.
Имеющиеся настройки импортируются автоматически; сохранённые логины и пароли
не выдаются браузеру. Пустые поля авторизации сохраняют прежние значения.
«Проверить» использует форму без сохранения; «Вернуть предыдущие настройки»
восстанавливает предыдущие подключения и маршруты.

Общие настройки доступны только администратору. Они сохраняются в `home.db`
(`network_proxy_config`); прежний вариант — `network_proxy_previous`.
Для TMDB панель дополнительно обновляет только `tmdb.proxyapi` и `tmdb.proxyimg`
в `init.conf`, который Lampac перечитывает без перезапуска. Остальные сервисы
применяют выбор к новым запросам. Проверка соединения не является проверкой
полного воспроизведения или качества результатов поиска.

При первом открытии используются существующие значения из описанных ниже
файлов и переменных. После первого сохранения через панель её маршруты имеют
приоритет для HomeMedia; ручные изменения старых `yt_proxy` и `kinopub.json.proxy`
больше не определяют маршрут этих клиентов.

Прокси нужны только если провайдер блокирует часть сервисов. Без них всё работает напрямую; **в проекте нет готовых прокси** —
укажите свой. В примерах `proxy.example` — условный адрес.

Поддерживаются HTTP и SOCKS5: `http://host:port`, `socks5://host:port`, `socks5://user:pass@host:port`.
Если в пароле есть символы `#`, `&`, `@`, `/` — задавайте прокси не через `.env`, а правкой `init.conf` (см. ниже), закодировав их в URL.

## 1. Где какой прокси

| Что ходит через прокси | Где настраивается | Переменная при первом запуске |
|---|---|---|
| **Lampac: TMDB** (данные и постеры) | `init.conf` → `tmdb.proxyapi`, `tmdb.proxyimg` | `TMDB_PROXY` |
| **Lampac: общий прокси** для модулей | `init.conf` → `globalproxy` (+ `globalnameproxy` у модуля) | `LAMPAC_GLOBAL_PROXY` |
| **Lampac: отдельный модуль** (трекер, онлайн-источник) | `init.conf` → блок модуля: `useproxy`, `proxy.list` | — |
| **YouTube** (поиск, потоки, подписки) | база `home.db`, ключ `yt_proxy` | `HOME_YT_PROXY` |
| **Кинопаб** (API) | `kinopub.json`, ключ `proxy` | `HOME_KP_PROXY` |
| **JacRed HomeMedia** (агрегатор `/jr`) | панель → «Состояние сервера» → поле JacRed; изначально напрямую | — |
| Channel Manager | не использует; источники берутся напрямую | — |

## 2. Lampac

### TMDB

Если TMDB недоступен (нет постеров и описаний) — задайте `TMDB_PROXY` в `.env` до первого запуска. Позже — правка `init.conf`:

```jsonc
"tmdb": {
  "proxyapi": { "useproxy": true, "proxy": { "list": [ "socks5://user:pass@proxy.example:1080" ] } },
  "proxyimg": { "useproxy": true, "proxy": { "list": [ "socks5://user:pass@proxy.example:1080" ] } }
}
```

### Общий прокси и отдельные модули

Один раз описываем прокси под именем, затем подключаем его нужным модулям. Задайте `LAMPAC_GLOBAL_PROXY` или добавьте в корень `init.conf`:

```jsonc
"globalproxy": [ { "name": "main", "list": [ "socks5://user:pass@proxy.example:1080" ] } ]
```

В блоке нужного модуля (трекер JacRed, онлайн-источник и т. п.):

```jsonc
"useproxy": true,
"globalnameproxy": "main"
// либо свой список только для этого модуля:
// "proxy": { "list": [ "socks5://user:pass@proxy.example:1080" ] }
```

`useproxystream: true` дополнительно пропускает через прокси сам видеопоток (обычно не нужно).

Точные имена полей и значения по умолчанию смотрите в файле `current.conf` в каталоге Lampac: он создаётся при старте и содержит все параметры.
Файл `init.conf` перечитывается без перезапуска.

## 3. YouTube

Прокси берётся из ключа `yt_proxy` в базе, а если он пуст — из переменной `HOME_YT_PROXY`. По умолчанию ключ пуст, поэтому прокси меняется
правкой `.env` и командой `docker compose up -d` (контейнер пересоздастся, данные сохранятся):

```bash
HOME_YT_PROXY=http://proxy.example:7890     # пусто — напрямую
```

Проверка: `curl http://<HOST_IP>:9118/yt/status`, в ответе поле `proxy`.
(Установки, где ключ `yt_proxy` записан в базе, продолжают использовать его; сменить его можно прямой записью в таблицу `kv` базы `home.db`.)

## 4. Кинопаб

`HOME_KP_PROXY` применяется один раз — при создании `kinopub.json`. Позже правьте ключ `proxy` в файле
(`/lampac/database/kinopub.json`); пустая строка — без прокси.

## 5. Типичная схема

Один прокси на всё: создайте его в сети (Clash/mihomo, sing-box и т. п.), укажите один адрес в `TMDB_PROXY`, `HOME_YT_PROXY`,
`HOME_KP_PROXY` и `LAMPAC_GLOBAL_PROXY` либо выберите подключение в панели. Прокси должен быть доступен контейнеру: `localhost` внутри контейнера — это сам контейнер,
используйте адрес хоста.
