# Dune: задержки открытия страниц, APK 1135

03.11.2026, сеть «Коробка». Приставка Dune Magic 4K Plus, модель tv175r,
192.168.1.101. После подтверждения RSA-разрешения ADB доступ получен.
Прямое подключение сверено по serial с ранее прочитанным HTTP-статусом Dune.
Временный SSH-forward для ADB закрыт; далее использовался прямой ADB этой приставки.

## Причина задержки

На Dune системный `com.android.webview` версии 66.0.3359.158. Код проверки
перехода из оболочки в Lampa использовал JavaScript optional chaining `?.`.
WebView 66 не поддерживает этот синтаксис. В журнале процесса APK 1134
повторялись `Uncaught SyntaxError: Unexpected token .`. Проверка запускается
каждые 100 мс и ожидает открытия до 60 секунд; ошибка не давала ей снять
оболочку, хотя целевая страница или меню уже могли быть открыты под ней.

В текущем WebView через DevTools отдельно проверен разбор: старое выражение
даёт SyntaxError, исправленные инициализация и проверка перехода разбираются
успешно. На сервере проверенные локальные страницы отвечали за 43–66 мс,
нагрузка 0.21–0.36, доступно около 2.9 GiB RAM; торможение серверной отдачи
в этом замере не воспроизвелось. Эти измерения не исключают задержек отдельных
внешних провайдеров и не являются длительным тестом утечек памяти.

## Исправление

В двух инъекциях JavaScript `MainActivity.mcOpen` заменён optional chaining на
совместимый доступ `(document.querySelector('.selectbox')||{}).textContent`.
Условия готовности страницы, отмена перехода и управление профилями сохранены.
Системный WebView и настройки приставки не менялись.

APK: `1.16.17-mc`, versionCode `1135`, пакет `app.lampac.home.mc`.
Размер `35205042` байт, SHA-256
`1331399f251a447506a2a3c3e411e14a239ab772995d7e45aab809649ad1daa9`.
Подпись совпадает с 1134:
`71ea04563313864b3f8e78995bfb5592eefa9d68c7822550f4cd960eaad31813`.

## Установка и приёмка

Владелец отдельно разрешил закрыть просмотр, обновить и запустить LMPC для теста.
Предыдущий APK 1134 сохранён в
`D:/tmp/lmpc-dune-tv-20261103/Dune-before-1134.apk`, его SHA совпал с релизом.
Установка выполнена поверх, с сохранением данных. Проверен SHA установленного APK.

Сборка Release, unit tests и lintVital прошли. Node-регрессии: legacy navigation,
семь проверок shell metadata и возврат из карточки — прошли. На самом устройстве
проверены реальные переходы с передачей фокуса из WebView оболочки в WebView Lampa:

| Действие | Измеренное время |
|---|---:|
| Открытие меню выбора | 2082 мс |
| Открытие поиска | 2450 мс |
| Открытие реальной карточки фильма 891621 | 1444 мс |

Время включает задержки команд и опроса DevTools/ADB, это не чистый рендеринг.
После обновления в проверенном журнале нового процесса ошибок Unexpected token .
не обнаружено. Сохранены сервер 192.168.1.197, прежний профиль и ID устройства,
АФР=true, DRC=0, проброс=false, туннелирование=false.

Приставка возвращена на домашний экран LMPC. Проверочный диалог и поиск закрыты,
временный DevTools-forward удалён. Новые профили не создавались. Видеопотоки
при этой проверке не запускались; работоспособность ТВ до неё подтвердил владелец.
