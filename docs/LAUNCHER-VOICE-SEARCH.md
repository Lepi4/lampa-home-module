# Поиск в лаунчере с пульта

В APK LMPC 1.16.44-mc (1162) внешний голосовой помощник может передать распознанный запрос прямо в поиск лаунчера с категориями.

Используется intent `app.lampac.home.action.LAUNCHER_SEARCH` для пакета `app.lampac.home.mc`. Строка запроса передаётся в стандартном extra `query` (`SearchManager.QUERY`). Приложение удаляет пробелы по краям, ограничивает запрос 500 символами и игнорирует пустой запрос.

```bash
adb shell am start -a app.lampac.home.action.LAUNCHER_SEARCH \
  -p app.lampac.home.mc --es query "Interstellar"
```

При холодном запуске запрос дожидается готовности WebView. Если приложение уже открыто, появляется поиск лаунчера, а предыдущий запрос заменяется. Кнопки «Назад» и «Домой» отменяют ожидающий запрос. Обычный `android.intent.action.SEARCH` сохраняет прежний поиск внутри Lampa.

Распознавание речи и назначение кнопки пульта выполняет внешний помощник. Этот APK добавляет приём запроса в лаунчере; установка распознавателя и его настройка выполняются отдельно.

Для выпуска проверены сборка `assembleMcRelease` с `lintVital`, синтаксис JavaScript, подпись APK и запуск на Android TV 11: холодный запуск, повторный запрос, стандартный поиск Lampa и переход обратно в лаунчер. Пользователь подтвердил поиск кнопкой микрофона на пульте. Русский и английский проверены с домашним Whisper, резервное распознавание — при временной недоступности сервера. Эти проверки относятся к настроенному телевизору; на других моделях требуется совместимый помощник и доступ к микрофону пульта.
