# Как участвовать в проекте

Спасибо за интерес к LMPC HomeMedia и Android TV. Проект находится в альфа-статусе, поэтому небольшие проверенные изменения предпочтительнее крупных рефакторингов.

## Предложить изменение

1. Создайте issue или обсуждение в GitVerse/GitHub: опишите проблему, ожидаемое поведение и способ проверки.
2. Для кода сделайте отдельную ветку от `master`.
3. Не смешивайте в одном PR разные темы: серверный модуль, APK, документацию и инфраструктуру.
4. В описании PR укажите: что изменено, зачем, какие проверки выполнены и какие ограничения остались.

## Требования к коду

- Сохраняйте существующий стиль и структуру файлов.
- Не добавляйте секреты, токены, cookies, пароли, `home.db`, резервные копии и приватные URL.
- Для C# соблюдайте текущие соглашения проекта; для JS — существующий стиль без сборщика.
- Для Android сохраняйте совместимость с flavor `mc`, minSdk 21 и текущей подписью релиза.
- Новые настройки профилей храните на сервере; клиент не должен быть единственным источником истины.
- Изменения поведения профилей, прав и прогресса сопровождайте тестом или воспроизводимым сценарием.

## Проверки перед PR

```bash
git diff --check

node server-mod/tests/panel-content.regression.cjs
node server-mod/tests/auth-routes.regression.cjs
python3 server-mod/tests/service-ui-base.regression.py
```

Android-сборка (JDK 17, Android SDK 34):

```bash
cd LAMPA
./gradlew assembleMcRelease -PappVersionCode=<code> -PappVersionName=<version>
```

Если проверка требует живого сервера или приставки, укажите это в PR и приложите результат ручной проверки.

## Коммиты

Формат сообщения:

```text
область: короткое действие в повелительном наклонении
```

Примеры:

```text
homemedia: не считать unknown-серию серией без русской озвучки
android: сохранять сессию при возврате из плеера
docs: обновить релизные версии
```

Не используйте `git reset --hard`, `git clean` и force-push в общих ветках.

## Ревью

Ревью выполняется владельцем репозитория. Ориентир по ответу — до 7 рабочих дней; это не гарантия SLA. Изменения, затрагивающие безопасность или совместимость с Lampac, могут потребовать дополнительной проверки.
